ERRORES COMETIDOS — LECCIONES APRENDIDAS (NO REPETIR)

1. datetime.utcnow() → DEPRECATED en Python 3.14

python
python
# ❌ NUNCA usar
datetime.utcnow()
datetime.datetime.utcnow()

# ✅ SIEMPRE usar
from datetime import datetime, timezone
datetime.now(tz=timezone.utc).isoformat()

2. datetime.UTC no existe

python
python
# ❌ NO existe
datetime.UTC

# ✅ Correcto
timezone.utc

3. Import de datetime en agentes

python
python
# SIEMPRE agregar al tope del archivo del agente
from datetime import datetime, timezone

# El import estático NO importa datetime como valor runtime:
from __future__ import annotations  # ← Esto NO trae datetime al runtime

4. No testear _approval_level en llamadas directas

El wrapper _wrap_with_hitl solo agrega _approval_level cuando se registra con MCP (register_with_mcp), NO cuando se llama el método directamente en tests.


5. Defaults de parámetros de filtros

python
python
# ❌ NUNCA usar enum como default
event_type: str = "dinner"
facility_type: str = "pool"

# ✅ SIEMPRE usar string vacío
event_type: str = ""
facility_type: str = ""

# RAZÓN: Al hacer list(), si el usuario no pasa el parámetro,
# filtra solo por ese valor y no devuelve todo.

6. Crear solo UNA versión de cada archivo

Si la respuesta se corta a mitad de código, NO volver a empezar desde cero. Pedir al usuario que confirme qué tiene copiado y continuar desde ahí. Mezclar dos versiones genera inconsistencias.

FRONTEND — RECOMENDACIONES EXPERTAS

Filosofía de Diseño para Club Privado

El público de un club privado elite es excepcionalmente diverso:

Adultos mayores (60-80+): Socios fundadores, poco tech-savvy, pantalla grande, contraste alto
Profesionales busy (35-55): CEOs, abogados, doctores — acceso desde celular, eficiencia
Jóvenes (18-35): Hijos de socios, nativos digitales, social features
Staff operativo (20-50): Recepción, mantenimiento, cocina — tablets, rapidez
Gerencia (40-60): Dashboards, decisiones, reportes

Principio rector: Si mi abuela de 75 años no puede hacer una reservación de cancha en 3 taps, el diseño falló.


Stack Recomendado

text
text
React 19 + TypeScript
Vite 6 (build tool)
Tailwind CSS v4
TanStack Query v5 (server state — cache, refetch, optimistic updates)
Zustand (client state — filtros, sidebar, tema)

Principios UX para Club Privado

text
text
1. CONTRASTE ALTO — WCAG AAA siempre. Adultos mayores necesitan contraste
   7:1 mínimo. Nada de texto gris claro sobre fondo gris.

2. BOTONES GRANDES — Mínimo 48x48px (WCAG). Preferiblemente 56x56px.
   Padding generoso. Adultos mayores con temblor en manos lo necesitan.

3. TIPOGRAFÍA ESCALABLE — El usuario debe poder aumentar tamaño de texto
   sin romper el layout. Usar rem, no px.

4. NAVEGACIÓN SIMPLE — Máximo 3 niveles de profundidad. Siempre visible
   dónde estás (breadcrumb). Botón "Inicio" siempre accesible.

5. FEEDBACK INMEDIATO — Cada acción tiene respuesta visual. Loading states
   claros. Confirmaciones con lenguaje humano, no técnico.

6. MODO OSCURO — Adultos mayores y staff nocturno lo necesitan. Toggle
   siempre visible. Recordar preferencia.

7. RESPONSIVE MOBILE-FIRST — El gerente revisa desde el celular a las 11pm.
   Recepción usa tablet. El socio viejo usa desktop grande.

8. PWA — Instalable. Funciona offline para datos cacheados. Push
   notifications para eventos y recordatorios.

9. ACCESIBILIDAD — ARIA labels en todo. Navegación por teclado.
   Screen reader compatible. Focus indicators visibles.

10. CALIDEZ VISUAL — Sombras suaves, bordes redondeados (8-12px),
    espacios generosos. Nada de diseños fríos o industriales.
