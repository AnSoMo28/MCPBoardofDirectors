═══ BLOQUE A: AUTH SYSTEM (JWT + RBAC) ═══

Nuevos archivos:
backend/src/club_mcp/auth/
├── __init__.py
├── jwt_service.py         Crear/verificar tokens HS256→RS256
├── models.py              User, Role, Permission Pydantic models
├── rbac.py                ROLE_PERMISSIONS matrix
├── middleware.py           FastAPI dependency injection
├── password_service.py    bcrypt hashing
└── seed_users.py          Datos demo: 1 socio, 1 staff, 1 admin, 1 junta

jwt_service.py:
  - TokenPair: access_token, refresh_token, token_type, expires_in
  - TokenPayload: sub, role, family_id, name, exp
  - Access token: 15 min TTL
  - Refresh token: 7 días TTL
  - Algorithm: HS256 (dev) → RS256 (prod)
  - create_token_pair(user_id, role, name, family_id) → TokenPair
  - verify_token(token) → TokenPayload

rbac.py:
  - Permission enum con ~30 permisos granulares
  - ROLE_PERMISSIONS: dict[str, set[Permission]]
  - Roles: SOCIO (6 perms), STAFF (8 perms), ADMIN (15 perms), JUNTA (5 perms)
  - check_permission(role, permission) → bool
  - TOOL_PERMISSION_MAP: dict[str, Permission] — cada tool mapeado a permiso mínimo

models.py:
  - User model (id, name, email, hashed_password, role, family_id, is_active)
  - UserCreate, UserLogin schemas

middleware.py:
  - get_current_user(credentials) → TokenPayload (FastAPI Depends)
  - require_permission(permission) → dependency factory
  - require_roles(*roles) → dependency factory

password_service.py:
  - hash_password(plain) → str
  - verify_password(plain, hashed) → bool

seed_users.py:
  - seed_demo_users() → crea 4 usuarios de prueba:
    carlos@castillo.cr / admin123 → SOCIO
    maria@castillo.cr / staff123 → STAFF
    gerente@castillo.cr / admin123 → ADMIN
    director@castillo.cr / junta123 → JUNTA

Tests: tests/unit/auth/
  - test_jwt_service.py (create, verify, expired, invalid)
  - test_rbac.py (permissions por role, tool mapping)
  - test_password_service.py (hash, verify, wrong password)


═══ BLOQUE B: API BRIDGE (FastAPI) ═══

Nuevos archivos:
backend/src/club_mcp/api/
├── __init__.py
├── app.py                 FastAPI app factory
├── dependencies.py        Auth dependencies (get_current_user, etc.)
└── routes/
    ├── __init__.py
    ├── auth.py            POST /api/auth/login, POST /api/auth/refresh, GET /api/auth/me
    ├── agents.py          POST /api/agents/{agent_name}/{tool_name}
    ├── chat.py            POST /api/chat (Claude conversational)
    └── health.py          GET /api/health

app.py:
  - create_api_app(mcp_server=None) → FastAPI
  - CORS middleware: allow localhost:5173
  - Include all routers
  - Mount under /api prefix

routes/auth.py:
  - POST /api/auth/login → validate email/password, return TokenPair
  - POST /api/auth/refresh → validate refresh token, return new TokenPair
  - GET /api/auth/me → return current user info

routes/agents.py:
  - POST /api/agents/{agent_name}/{tool_name}
  - Body: params dict
  - Verify JWT token
  - Check TOOL_PERMISSION_MAP for required permission
  - Look up agent by name, call tool with params
  - Return tool response

routes/chat.py:
  - POST /api/chat
  - Body: { message, conversation_history }
  - Verify JWT, get user role
  - Call ClaudeService.chat()
  - Return response

routes/health.py:
  - GET /api/health
  - Return: { status, agents_count, tools_count, version }

dependencies.py:
  - Re-export from auth/middleware.py for convenient imports

Tests: tests/unit/api/
  - test_auth_routes.py
  - test_agents_routes.py
  - test_health.py
