Proyecto

Aplicación web React para la gestión integral del Castillo Country Club, un club de campo de alto nivel en Costa Rica. SPA con:


React 19 + TypeScript
React Router v7 (createBrowserRouter)
TanStack Query (@tanstack/react-query) para datos del servidor
Zustand para estado local (auth, theme, sidebar)
Framer Motion para animaciones
Lucide React para iconos
Tailwind CSS 4 para utilidades (via @tailwindcss/vite)
Backend MCP (Model Context Protocol) — los datos vienen de herramientas MCP, no de REST APIs convencionales
Backend en FastAPI corriendo en localhost:8001 (Vite proxy: /api → localhost:8001)
No hay API REST tradicional. Todo se comunica via MCP tools excepto auth.

Arquitectura MCP

Patrón de comunicación

text
text
Frontend → useMCPQuery(service, tool, params) → MCP Server → Agente → Tool → Response

No hay REST. Todo pasa por el hook useMCPQuery que es un wrapper de TanStack Query.


Hook principal

typescript
typescript
useMCPQuery<T>(
  service: string,        // "finance", "reports", "events", etc.
  tool: string,           // "get_board_report", "get_financial_overview", etc.
  params: object,         // parámetros del tool
  options?: QueryOptions  // staleTime, enabled, placeholderData, etc.
)
