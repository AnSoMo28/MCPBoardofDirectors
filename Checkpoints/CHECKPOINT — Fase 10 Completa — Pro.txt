3. PATRONES ESTABLECIDOS

Patrón CRUD con HITL (NUEVO — establecido en Fase 10)

Cuando un agente tiene tools con action parameter (list/get/create/update_status):


text
text
1. List (auto-load)     → useMCPQuery con staleTime, action="list"
2. Get (on-demand)      → useMCPQuery con enabled condicional, action="get"
3. Create (mutation)    → useMCPMutation, action="create"
                         → backend retorna pending_approval
                         → Toast informativo
                         → ApprovalQueue muestra el item
4. Update status        → useMCPMutation, action="update_status"

Este patrón se usa en: optimize_pricing, suggest_new_activities, generate_quarterly_insights.


Patrón AI de 3 Niveles (establecido en Fase 9, confirmado en Fase 10)

Nivel	Patrón	Ejemplos Fase 10
1. Datos (auto-load)	useMCPQuery con staleTime	identify_social_clusters, optimize_pricing list, suggest_new_activities list
2. Inteligencia (on-demand)	useMCPQuery con enabled: shouldFetch + botón	generate_family_recommendations, detect_scheduling_conflicts, predict_event_attendance
3. Two-phase	Dos triggers separados	No aplicó en Fase 10 (sí en Fase 9: wellness_insights → wellness_predict)

Patrón de Sub-tabs (NUEVO — establecido en Fase 10)

Cuando un módulo tiene herramientas de administración (HITL) separadas de dashboards de visualización:


text
text
DetailTabs (vistas principales)
  └── Tab "Administración"
        └── Sub-tab bar (toggle local con buttons)
              ├── Precios → PricingOptimizer
              └── Actividades → ActivitySuggester

Razón: Los CRUDs HITL son herramientas de gestión, no dashboards de visualización.



4. DECISIONES DE DISEÑO

#	Decisión	Alternativa descartada	Razón
1	Admin como tab dentro de RecommendationsDashboard	Dashboard separado o link externo	Centraliza todo en un módulo, evita fragmentación de navegación
2	Sub-tabs (Precios/Actividades) en vez de DetailTabs	DetailTabs para 2 items	Overengineering: DetailTabs es para 3+ secciones con ARIA. 2 items → toggle simple
3	identify_social_clusters como auto-load	On-demand con botón	Es una lista de datos pre-computados, NO análisis pesado. Sinónimo de "list_families"
4	SVG radial gauge 360° en PredictAttendance	Gauge 270° como WellnessScoreCard	Predicción es un solo número, no score compuesto. Gauge circular completo es más intuitivo
5	Date picker default = hoy	Sin default	UX: usuario típicamente quiere conflictos de hoy, no tiene que navegar
6	Placeholder import eliminado de RecommendationsDashboard	Mantenerlo por si acá	No se usa más después de B3+B4. Si B4 lo necesita, se re-agrega
7	Toggle nativo HTML para similar_clubs_offer	Switch custom con Toggle component	No existe Toggle shared. Implementación simple con role="switch" + aria-checked
