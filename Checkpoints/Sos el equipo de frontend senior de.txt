═══════════════════════════════════════════════════
PATRONES DE CÓDIGO
═══════════════════════════════════════════════════

Imports: usar @/ alias (configurado en vite.config.ts + tsconfig)
Estilos: Tailwind classes con cn() utility. Variables CSS con var(--color-xxx).
Componentes: forwardRef para inputs/buttons. Props interfaces separadas.
API: callMCPTool(agent, tool, params) → POST /api/agents/{agent}/{tool}
Hooks: useMCPQuery(agent, tool, params) para consultas, useMCPMutation para acciones.
Auth: Zustand persist store con JWT. Roles: SOCIO, STAFF, ADMIN, JUNTA.
Permisos: PermissionGate component + checkPermission() function.
UI exports: todo sale de @/shared/components/ui/index.ts
