### Patrón B: Cross-Agent On-Demand Section (B2)

```tsx
function CrossAgentSection({ summary }) {
  const [shouldFetch, setShouldFetch] = useState(false);
  const query = useMCPQuery("other_agent", "tool", {}, { enabled: shouldFetch });

  // 1. CTA card → Button "Consultar/Verificar"
  if (!shouldFetch) return <CTACard />;

  // 2. Loading → Skeleton
  if (query.isLoading) return <Skeleton />;

  // 3. Error → SectionError con retry
  if (query.isError) return <SectionError />;

  // 4. Empty → green "all clear" card
  if (empty) return <AllClearCard />;

  // 5. Results → data + cross-reference insight con summary
  return <Results insight={buildInsight(data, summary)} />;
}
```

**Clave:** El `insight` siempre combina datos del agente externo CON el summary del executive. Ejemplo: "Hay 4 alertas de cumplimiento abiertas, 1 crítica. Con 12 eventos programados, recomendamos resolver antes del próximo evento."

## 9. DECISIONES DE DISEÑO TOMADAS

| Decisión | Alternativa descartada | Razón |
|----------|----------------------|-------|
| 2 queries separadas (executive + pulse) | 1 query consolidada | Más granular, staleTime diferenciado, más fiel al backend real |
| Health Score compuesto | Solo KPIs individuales | "One metric that matters" — el admin ve UN número |
| AI Advisor con acciones navegables | Solo texto narrativo | Las acciones convierten insights en workflow |
| Cross-agent: Compliance + Facilities | Solo compliance | Cubre 90% del valor operativo diario |
| Client-side intelligence + deep on-demand | Todo on-demand | Layer 1 es instantáneo (0 latency), Layer 2 es profundo |
| Domain selector en anomalies | Solo "analizar todo" | Permite foco administrativo por área |
| Positive recs como compact cards | Mismo layout que critical | Las buenas noticias no necesitan el mismo peso visual |
| SVG ring para health score | Barra horizontal o número | Más impacto visual, diferenciador de producto |
| `compliance_alert_list` como cross-agent en DailyBriefing | Solo en ComplianceCheck | El admin necesita ver compliance status sin cambiar de tab |
| `generate_quarterly_insights` como deep layer | Auto-cargar | Rule #19: on-demand siempre con CTA explícito |
