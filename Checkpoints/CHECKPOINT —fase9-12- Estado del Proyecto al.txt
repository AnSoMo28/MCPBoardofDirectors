ERRORES COMETIDOS — LECCIONES APRENDIDAS (NO REPETIR)


1.datetime.utcnow() → DEPRECATED en Python 3.14. SIEMPRE usar:
python
python
from datetime import datetime, timezone
datetime.now(tz=timezone.utc).isoformat()
NUNCA usar datetime.utcnow() ni datetime.datetime.utcnow().


2.
datetime.UTC no existe → Es timezone.utc, NO datetime.UTC.

3.
datetime importado en agent → SIEMPRE agregar from datetime import datetime, timezone al tope del archivo del agente cuando algún método usa datetime.now(). El import estático arriba (from __future__ import annotations) NO importa datetime como valor de runtime.

4.
No testear _approval_level en llamadas directas → El wrapper _wrap_with_hitl solo agrega _approval_level cuando se registra con MCP (register_with_mcp), NO cuando se llama el método directamente en tests.

5.
Defaults de parámetros de filtros → SIEMPRE usar "" (string vacío) como default para parámetros como event_type, facility_type, engagement_level, etc. NUNCA usar el valor de un enum como default (ej: "dinner", "pool"). Porque al hacer list, si el usuario no pasa el parámetro, filtra solo por ese valor y no devuelve todo.

6.
Crear solo UNA versión de cada archivo → Si la respuesta se corta a mitad de código, NO volver a empezar desde cero. Pedir al usuario que confirme qué tiene copiado y continuar desde ahí. Mezclar dos versiones genera inconsistencias (ej: V1 con name/value vs V2 con monetary_value).

7.
Tests con seed helpers y contadores → Cuando se usa un seed helper con un valor default (ej: loyalty_points=1200) y después se llama a una función que suma puntos, el assert debe considerar el valor sembrado + el incremento. Mejor sembrar con valor 0 por defecto y pasar el valor explícito en el test.
